# Outcome

在分组专属倍率管理中增加模型限制开关及模型下拉多选，开启后仅选中模型应用专属倍率，其他模型回退分组默认倍率。

# Scope

覆盖现有专属倍率弹窗、分组级配置读写持久化、网关倍率选择及必要缓存和回归检查。每个分组共用一套模型限制开关与模型列表，约束该分组所有用户的专属倍率。模型候选复用现有分组模型候选接口；按客户端请求的模型 ID 精确匹配，不随上游模型映射变化。关闭限制保留已选列表但不应用限制；已有分组默认关闭。配置与倍率修改沿用显式保存及取消语义。

## 目录结构

### 新建

- backend/migrations/ — 模型限制持久化字段迁移，具体所属表随配置粒度确定。
- 相关模块测试文件 — 校验开启、关闭、命中及未命中的计费行为。

### 修改

- frontend/src/components/admin/group/GroupRateMultipliersModal.vue — 模型限制开关及下拉多选。
- frontend/src/api/admin/groups.ts、frontend/src/types/、frontend/src/locales/ — 配置契约和文案。
- backend/internal/handler/admin/、backend/internal/service/、backend/internal/repository/ — 配置校验、持久化及所有专属倍率消费路径。
- backend/ent/ — 如配置落入分组实体，同步 schema 及生成代码。

### 删除

无。

### 明确不建

- 独立模型目录系统 — 优先复用项目已有模型候选来源。
- 新的模型访问权限机制 — 本需求仅控制专属倍率适用范围。

# Non-goals

不改变模型访问权限、RPM 配额和模型基础定价；不发布版本或部署；不重新设计整个管理弹窗。

# Acceptance examples

- A1：关闭模型限制时，保持原有专属倍率行为，旧配置默认不受限制。
- A2：开启模型限制并选中模型后，命中模型应用对应用户专属倍率，未命中模型使用分组默认倍率。
- A3：保存后重新打开，开关与模型选择正确回显；取消未保存修改不改变服务端配置。

- A4：开启且没有有效模型选择时，前后端均拒绝保存并提示至少选择一个模型，不改变已存配置。
- A5：同一模型在各用户间采用各自专属倍率；未设置专属倍率的用户仍按分组默认倍率；分组间配置互不影响。
- A6：以客户端请求模型 ID 精确匹配，上游映射不会扩大适用范围；各网关计费及预估路径遵守相同规则，缓存不得使未选模型误用专属倍率。
- A7：模型候选读取失败显示错误并允许重试，不静默清除已保存的选择；关闭开关保留选择，重新开启可恢复。

# Decisions

- Q1 已确认：整个分组共用一套模型限制。
- Q2 已确认：开启限制且未选择模型时禁止保存。
- 完整 Shape 待最终确认：默认关闭；精确匹配客户端请求模型 ID；未选中回退分组默认倍率；不限制模型调用权限。
