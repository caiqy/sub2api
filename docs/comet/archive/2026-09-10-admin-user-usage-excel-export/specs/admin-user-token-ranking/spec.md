# 管理员用量用户排行规格

## 目标

在管理员用量界面的“用户排行”表格中增加“用户名”列，并提供导出 Excel 功能，便于管理员导出用户消费排行报表。

## 展示

- 在“用户排行”表格表头中，在“#”序号列后、“用户”列前增加“用户名”列。
- 表头文字：中文为“用户名”，英文为“Username”。
- 表格数据行：显示对应用户的 `username`。若 `username` 为空字符串或未定义，回退显示用户的邮箱 `email`；若两者均无，显示 `-`。
- 表格空状态和加载状态的 `colspan` 相应递增 1。

## 导出 Excel

- 工具栏右侧在 Top 下拉选择器旁增加“导出 Excel”操作按钮。
- 当处于加载状态或当前数据列表为空时，按钮为 disabled 状态。
- 点击导出按钮时，将当前列表的数据导出为 `.xlsx` 格式文件并触发浏览器下载。
- 文件名规则为：`user_token_ranking_{startDate}_to_{endDate}.xlsx`。
- Excel 包含一个 Sheet，表头四列分别为：
  1. `用户名`
  2. `请求数(次)`
  3. `总Token(亿)`
  4. `计费额度(美元)`
- 数据映射：
  - 用户名：用户的 `username`，若为空则填入邮箱 `email`，若两者均无则为空字符串。
  - 请求数(次)：用户的 `requests`（数值）。
  - 总Token(亿)：用户的 `total_tokens / 100000000`（数值，保留4位小数）。
  - 计费额度(美元)：用户的 `actual_cost`（数值，保留4位小数）。

## 验收场景

- A1：表格新增“用户名”列，有用户名时展示用户名，用户名为空时回退展示邮箱，均无时展示“-”。
- A2：工具栏展示“导出 Excel”按钮，无数据或加载中处于禁用状态。
- A3：点击“导出 Excel”按钮，成功调用生成并下载 xlsx 文件。
- A4：导出的 Excel 文件包含指定的 4 列，用户名为空时填入邮箱，数值精度与单位换算正确。
- A5：国际化资源在中英文下均完整支持。
