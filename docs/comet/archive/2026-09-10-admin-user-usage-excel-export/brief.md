# 目标

在管理员后台用量页面的“用户排行”表格中，在“用户”列前面增加“用户名”列以便直观识别用户身份；同时提供导出 Excel 功能，支持将当前用户用量排行导出为包含“用户名、请求数(次)、总Token(亿)、计费额度(美元)”的 Excel 表格。

- 修改 `UserTokenRanking.vue`，在“用户”列前新增“用户名”列。
- 数据来源于接口已返回的 `item.username`，为空时回退显示 `item.email`（若均无则显示 `-`）。
- 在 `UserTokenRanking.vue` 顶部操作栏右侧增加“导出 Excel”按钮，无数据或加载中时禁用。
- 点击导出时，将当前排行列表（`items`）导出为 .xlsx 文件。
- 导出的 Excel 包含 4 列，表头分别为：`用户名`、`请求数(次)`、`总Token(亿)`、`计费额度(美元)`。
- 导出的“用户名”字段在 `username` 为空时填入用户的邮箱 `email`。
- 数值转换：请求数为整数，总Token(亿)转换为以“亿”（$10^8$）为单位的数值，计费额度(美元)为实际计费金额（数值）。
- 补充中英文 i18n 资源和针对性前端测试。

# 非目标

- 不修改后端接口与数据库，后端接口已提供 `username` 字段。
- 不影响用量明细等其他表格的布局与导出。
- 不改变用户点击行跳转明细的行为与逻辑。

# 验收示例

- A1：在“用户排行”表格中，“#”序号列后、“用户”列前显示“用户名”列；用户有 username 时展示其用户名，无 username 时回退展示邮箱（若两者均无展示 `-`）。
- A2：在“用户排行”工具栏右侧展示“导出 Excel”按钮；当列表无数据或正在加载时，按钮处于禁用状态。
- A3：在列表有数据时点击“导出 Excel”，触发生成并下载 Excel 文件（.xlsx）。
- A4：导出的 Excel 文件表头为 `用户名`、`请求数(次)`、`总Token(亿)`、`计费额度(美元)`；“用户名”列优先为 username，为空时填入邮箱；数据行中总Token换算为以“亿”为单位并保留4位小数，计费额度保留4位小数。
- A5：在中英文语言切换下，表格列名与操作按钮文案均正确适配国际化，键名保持完整。

# 约束与不变量

- 保持现有的表格样式、斑马纹/暗黑模式及行点击交互不变。
- 导出使用现有依赖 `xlsx` 和 `file-saver`，不引入新依赖。
- 不修改表格的原有列宽度比例与排列合理性。

# 决策

- 决策 1：导出的数据范围为当前表格呈现的排行数据（受当前筛选、时间范围与 Top N limit 限制），与界面展示一致，点击即刻前端生成下载，交互无延迟。
- 决策 2：表格与 Excel 导出中，若用户无用户名（空字符串或 null/undefined），回退填入用户的邮箱 `item.email`；若两者均无，表格显示占位符 `-`，Excel 中留空。
- 决策 3：导出格式中，总Token(亿)以 $total\_tokens / 10^8$ 计算，保留 4 位小数（纯数字，方便后续 Excel 求和统计）；计费额度(美元)以 `actual_cost` 计算，保留 4 位小数（纯数字）。
- 决策 4：复用现有的 i18n 体系，在 `admin.usage.tokenRanking` 下维护新增键名，保证 `check:i18n` 校验通过。
