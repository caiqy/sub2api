# Usage Body Column Visuals

## Behavior

管理员使用记录表的列顺序必须将请求体信息放在费用之后、延迟之前：

`TOKEN → 费用 → 请求体 → 延迟 → 时间`

原“体积”列的显示名称为“请求体”。该列继续显示三行：请求体输入大小、响应体输出大小和输入加输出的总计大小。缺失或无效大小显示 `-`。

请求体列左侧竖条根据请求体大小着色，并使用与延迟列相同的颜色语义：

| 请求体大小 | 颜色 |
| --- | --- |
| 空、非有限数或负数 | 中性灰 |
| `0` 至 `1 MiB`（含） | 绿色 |
| 大于 `1 MiB` 至 `2 MiB`（含） | 黄色 |
| 大于 `2 MiB` 至 `4 MiB`（含） | 橙色 |
| 大于 `4 MiB` | 红色 |

阈值使用二进制 MiB，即 `1024 * 1024` 字节。请求体大小只影响请求体列的竖条，不改变数值格式或延迟列的现有色条逻辑。

## Scope

该 capability 只涉及管理员使用记录表的前端展示和前端本地校验。后端接口、数据库字段、数据计算、导出行为以及其他页面不变。
