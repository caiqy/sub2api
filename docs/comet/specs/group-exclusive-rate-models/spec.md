# 分组专属倍率的模型适用范围

## Purpose

管理员为每个分组设置一套共用模型限制，控制该分组下用户专属倍率的适用模型，不改变模型访问权限或基础定价。

## Requirements

### Requirement: 分组配置与兼容

分组专属倍率弹窗增加“限制适用模型”开关。已有分组默认关闭，关闭时保持既有所有模型适用专属倍率的行为；关闭时保留已选模型列表，重新打开可恢复。组内所有专属倍率条目共用限制，但每位用户继续使用其各自的倍率。没有专属倍率的用户继续使用分组默认倍率。

#### Scenario: 默认兼容

Acceptance: A1

WHEN 旧分组未配置或管理员关闭限制
THEN 所有模型继续沿用原有专属倍率行为。

#### Scenario: 分组与用户隔离

Acceptance: A5

WHEN 不同用户在同组请求选中模型，或请求另一分组
THEN 使用对应用户及分组的倍率与限制，不串用配置；没有专属倍率时使用分组默认值。

### Requirement: 模型选择与保存

开启后展示可搜索的下拉多选，复用现有分组模型候选接口；展示并保留已保存选择，即使候选列表后续变化，也不得静默丢弃。前后端都校验开启时至少存在一个非空模型 ID。配置沿用弹窗显式保存和取消语义，保存失败不提示成功、不丢弃编辑内容。

#### Scenario: 保存与取消

Acceptance: A3

WHEN 保存模型限制后重新打开，或修改后取消
THEN 已保存开关与选择正确回显；取消不修改服务端数据。

#### Scenario: 空选择校验

Acceptance: A4

WHEN 开启限制但没有有效模型选择
THEN 前后端拒绝保存，提示至少选一个模型，已保存配置保持不变。

#### Scenario: 候选异常与开关恢复

Acceptance: A7

WHEN 候选读取失败或关闭后重新开启限制
THEN 失败时显示错误并可重试，已有选择保留；重新开启恢复所选模型。

### Requirement: 计费匹配

限制开启时按客户端请求的模型 ID 精确匹配选中集合；命中才使用该用户在该分组的专属倍率，未命中则使用分组默认倍率。该限制不授予或撤销调用权限，不新增通配符规则。上游模型映射不改变匹配对象。网关实际计费、预估及影响计费的倍率消费路径使用一致规则；缓存及鉴权分组快照必须携带正确配置，不允许同组已选模型的缓存倍率污染未选模型。

#### Scenario: 命中与回退

Acceptance: A2

WHEN 分组默认倍率为 0.225，用户专属倍率为 0.12，限制仅选中模型 A
THEN 请求 A 使用 0.12，请求未选模型 B 使用 0.225。

#### Scenario: 映射与缓存一致

Acceptance: A6

WHEN A 映射为上游 B，且连续请求命中与未命中的模型，或更新限制后请求
THEN 按客户端模型 ID 判断，预估与最终计费保持一致，配置遵循现有缓存失效机制，未选模型不得复用选中模型的专属倍率。
