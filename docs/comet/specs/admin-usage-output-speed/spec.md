# 管理员使用记录输出速度

## 目标

管理员使用记录表格应在不增加表格列宽的前提下展示每次请求生成阶段的输出速度，帮助管理员同时判断首字延迟、总耗时和持续生成性能。

## 展示

- 输出速度仅在管理员使用记录表格展示。
- 现有“延迟”单元格保持左侧健康色条，并按“首字”“总耗时”“速度”三行排列。
- “速度”标签使用与已有标签相同的次要文本样式。
- 有效速度使用一位小数、等宽数字和 `tok/s` 单位，例如 `70.6 tok/s`。
- 速度文本可使用天蓝色与耗时健康度颜色区分，但不表达快慢等级。
- 无法计算时显示 `-`，并保留第三行以维持各记录对齐。

## 计算规则

输出速度定义为：

```text
output_tokens * 1000 / (duration_ms - first_token_ms)
```

只有以下条件同时满足时才计算：

- `output_tokens` 是有限且不小于 0 的数；
- `duration_ms` 和 `first_token_ms` 均为有限数；
- `duration_ms > first_token_ms`。

结果必须为有限数。有效区间内 `output_tokens=0` 的结果显示为 `0.0 tok/s`。

## 范围隔离

- 共享 `UsageTable` 提供默认关闭的管理员输出速度展示属性。
- 管理员 `UsageView` 显式开启该属性。
- 普通用户 `UsageView` 不开启该属性，因此现有布局与内容保持不变。
- 后端 DTO、API、持久化、Excel 导出、筛选和排序均不改变。

## 验收

- A1：`2016 * 1000 / (34520 - 5960)` 显示为 `70.6 tok/s`。
- A2：缺少任一计时字段或生成阶段耗时非正时显示 `-`。
- A3：有效计时区间内零输出显示 `0.0 tok/s`。
- A4：管理员延迟单元格保留既有健康色条及耗时颜色，且表格列集合不变。
- A5：普通用户记录不展示速度，后端契约无变化。
